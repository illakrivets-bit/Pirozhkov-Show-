# Pirozhkov Show 🎉

A playful 30-second visual party for Android and desktop browsers.

## Features
- 30-second animated rainbow show with changing backgrounds, floating stickers and funny pop-up captions.
- Add your own photos from the device; they appear in the animation.
- Optionally choose an audio file stored on your device. The app does not include or download copyrighted music.
- Play, pause and stop controls, plus a visible countdown and progress bar.
- Installable PWA with a lightweight offline app shell.

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages. For PWA installation and offline caching, use an HTTPS address (GitHub Pages works).

## On Android
Open the published HTTPS page in Chrome → menu ⋮ → **Install app** or **Add to Home screen**.

## Media and privacy
Photos and audio are selected locally in your browser and are not uploaded by this app. The app contains no bundled song audio or song lyrics. Use media you have permission to use.

## Controls
Choose photos and optional audio, then tap **START THE SHOW**. The animation ends automatically after 30 seconds. You can pause or stop it at any time.
